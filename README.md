## ⚙️ Getting Started

You can run the portfolio locally without installing any dependencies.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate into the project folder

```bash
cd YOUR-REPOSITORY
```

### 3. Open the website

Open `index.html` directly in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 🌍 Deployment

The portfolio can be hosted for free using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Under Build and Deployment, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save your settings.
7. Access your published portfolio using the GitHub Pages URL provided by GitHub.
